## 1. Crear un array

Crea un array amb aquests servidors:
```text

```
Guarda'l dins de:
```powershell
$servidors
```
Mostra tot el contingut de l'array.

## 2. Accedir a posicions
Amb l'array anterior, mostra:

- el primer servidor;
- el segon servidor;
- el quart servidor.

![alt text](exercici2.png)

Respon:

**Quina és la posició del primer element d'un array?**

La posició 0. Per tant, el segon és el 1, el tercer el 2 i el quart el 3.
