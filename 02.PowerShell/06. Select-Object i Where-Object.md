## 2. Seleccionar propietats i objectes

Amb `Get-Process`, construeix ordres que permetin:

1. mostrar només `Name` i `CPU`;
    Get-Process | Select-Object Name, CPU
    ![alt text](imatge4.png)
2. mostrar només `Name`, `Id` i `CPU`;
    Get-Process | Select-Object Name, Id, CPU
    ![alt text](imatge5.png)
3. mostrar només els cinc primers processos;
    Get-Process | Select-Object -First 5
    ![alt text](imatge6.png)
4. mostrar només els tres últims processos.
    Get-Process | Select-Object -Last 3
    ![alt text](imatge7.png)

Respon:

**Quina diferència hi ha entre seleccionar propietats i seleccionar objectes?**

>Quan fem un Get-Process ens dona una llista de tots els processos, aquets processos són "objectes" que dins seu tenen propietats.

## 3. Ordenar i seleccionar

Construeix un pipeline que mostri els **cinc processos amb més CPU**.

La sortida ha de mostrar únicament:

```
Name
Id
CPU
```

Compara després aquestes dues estratègies:

```
ordenar → seleccionar 5
```
![alt text](imatge8.png)

i:

```
seleccionar 5 → ordenar
```
![alt text](imatge9.png)

Respon:

1. Fan el mateix?

> No, l'estretegia A mostra els 5 processos amb més CPU de tot el sistema. En canvi l'estretegia B mostra només 5 processos qualssevols i els ordena entre ells.
    
2. Per què?

> Perquè l'ordre dels passos importen. En el primer cas s'ordenen tots els processos i després es trien els 5 primers, osigui que la tria es fa sobre una llista ja ordenada. En el segon cas primer es retalla la llista a 5 elements, sese cap criteri de CPU, i després s'ordena només aquest petit grup.
    
3. Quants processos rep `Sort-Object` en cada cas?

> El el cas "a" rep tots els processos en canvi en el cas "b" els rep tots.

## 5. Entendre `$_`

Utilitza:

```
$numeros = 5, 20, 3
```

i analitza:

```
$numeros |
    Where-Object { $_ -gt 10 }
```
![alt text](imatge14.png)

Completa:

|Valor de `$_`|Resultat de `$_ -gt 10`|Passa el filtre?|
|---|---|---|
|5|False|No|
|20|True|Sí|
|3|False|No|

Explica amb les teves paraules:

**Què representa** `$_`**?**

> Respresenta l'element actual que està passant pel pipeline en aquell moment, el que Where-Object analitza. Com que la variable numeros té tres elements, el `$_ -gt 10` s'executara tres vegades, i cada cop valdra una cosa diferent, primer 5, després 20 i finalment 3.

## 6. Filtrar objectes per propietats

Executa:

```
Get-Service
```

Construeix un pipeline que mostri únicament els serveis que estan en execució.

La sortida final ha de mostrar només:

```
Name
Status
```
![alt text](imatge15.png)

Després construeix-ne un altre que mostri els serveis que **no** estan en execució.

![alt text](imatge16.png)

Respon:

1. Què representa `$_`?

> Representa l'element actual que està passant pel pipeline, cada servei que el Where-Object rep de Get-Service.
    
2. Què representa `$_.Status`?

> Representa la propietat Status del servei actual
    
3. Què fa `Where-Object` amb els objectes que no compleixen la condició?

> El Where-Object el que fa és descartar-los, només deixa continuar els que tenen la condició de True.
    
4. Què fa després `Select-Object`?

> El Select-Object rep els serveis que han passat el filtre i només es quedan amb les propietats indicades com Name i Status.
